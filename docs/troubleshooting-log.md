# Git 트러블슈팅 기록

실제 수행 후 참여자·상황·명령·전후 결과·주의점·PR/커밋 링크를 기록합니다.
안내나 빈 양식만 있는 항목은 수행 완료가 아닙니다.

| 담당 | 실습 | 상태 |
|---|---|---|
| 1번 (`parkhojeong`) | amend | 수행 및 기록 준비 중 |
| 2번 | reset --soft | 미수행 — 담당자가 직접 진행 |
| 3번 | revert | 미수행 — 담당자가 직접 진행 |
| 4번 | stash / stash pop | 미수행 — 담당자가 직접 진행 |

## 1번: amend

공개하지 않은 최근 로컬 커밋의 메시지를 더 구체적으로 고칩니다.
실제 명령과 전후 커밋 정보는 수행 후 기록합니다.

## 2번: reset --soft

- 참여자:
- 상황·기준 브랜치:
- 공개 전 커밋과 부모 커밋:
- 실제 명령:
- reset 후 HEAD·index·작업 파일 상태:
- 변경을 유지한 채 다시 커밋한 결과:
- 주의점과 선택 이유:
- PR·커밋·증빙 링크:

원격에 공개하지 않은 본인 실습 커밋으로만 수행합니다.

## 3번: revert

- 참여자:
- 상황·기준 브랜치:
- 원격에 push한 대상 실습 커밋:
- 실제 명령:
- 새로 생긴 revert 커밋과 되돌린 파일:
- 기존 이력이 보존되었음을 확인한 결과:
- 주의점과 reset 대신 선택한 이유:
- PR·커밋·증빙 링크:

자신의 작업 브랜치에 올린 실습용 변경을 되돌립니다. main에 직접 push하지 않습니다.

## 4번: stash / stash pop

- 참여자:
- 상황·기준 브랜치:
- 보관 전 작업 파일·diff:
- 실제 명령과 stash 식별 정보:
- 보관 후 작업 트리·브랜치 전환 결과:
- 원래 브랜치 복귀·pop 후 복원된 diff:
- 주의점과 선택 이유:
- PR·커밋·증빙 링크:

충돌 해결을 먼저 커밋한 뒤 별도의 미커밋 변경으로 실습합니다.
